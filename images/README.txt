Put the finished pictures in this folder.

Name each file after the spot's App ID, then the time of day, then .jpg:
  thk-morning.jpg   thk-noon.jpg   thk-evening.jpg   thk-night.jpg
(thk is the App ID for Thian Hock Keng Temple. Copy each spot's App ID from the Image tracker sheet.)

Which one shows: Morning is 5am to 11am, Noon is 11am to 5pm, Evening is 5pm to 8pm, Night is 8pm to 5am,
or whatever time of day the visitor picks with the buttons at the top of the app.
A file with no time of day, like thk.jpg, is used for any time that has no picture of its own.
A spot with no pictures at all keeps its placeholder art.

Aim for about 1120 x 800 pixels (or smaller) and under 100 KB each. All lowercase, exactly .jpg.
