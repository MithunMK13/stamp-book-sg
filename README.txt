STAMP BOOK SG: how to put it online (no coding)

What this folder is
  index.html            the app
  manifest.webmanifest  lets phones install it like an app
  sw.js                 lets it work with a poor signal after the first visit
  icons/                the app icon
  images/               your pictures go here (see the README inside)

Easiest way to publish it (free)
  1. Make a free account at a static hosting site such as Netlify, Cloudflare Pages or GitHub Pages.
  2. Drag this whole folder onto the site's upload or "deploy" area.
  3. It gives you a web address starting with https://. Open it on your phone to test.
  Check the host's current instructions, as screens change.

Putting it on a phone like an app
  iPhone (Safari): open the address, tap Share, then Add to Home Screen.
  Android (Chrome): open the address, tap the menu, then Install app or Add to Home screen.

Adding pictures later
  Put the pictures into the images folder and upload the folder again. No other change is needed.

Your own address (optional)
  Buy a domain name (usually about US$10 to 15 a year; check current prices) and connect it in the host's settings.

Location and privacy
  The app checks location only when someone taps Stamp it, and keeps stamps only on their own phone.
  Location only works on https:// addresses, which all the hosts above provide.
